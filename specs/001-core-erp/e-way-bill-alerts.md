# E-way Bill Alert Requirements

- Alert must be shown as a popup notification in the UI.
- Alert timing must be configurable (default: 8 hours before expiry, but user can set window).
- Alert must include: LR No, E-way Bill No, Expiry Date, Days/Hours Remaining, Action Link.
- Alert logic must comply with Indian law (GST E-way Bill rules).
- Admins can override alert window per user or globally.
